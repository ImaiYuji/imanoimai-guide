Android のいれかた

端末によって言葉がすこし違うから、似ている言いかたをさがしてね。

  1. 1

    まずダウンロード

    下のボタンを Android の端末で 押してね。パソコンじゃなくて、アプリを入れたい端末で開くのがポイント！

    ダウンロードimanoimai-1.1.1.apk ／ 約 30MB
    ボタンを押すとすぐ保存がはじまるよ。 「このファイルは危険かも」みたいな確認が出たら、そのまま続けて大丈夫。ストアを通っていないアプリだと、どれでも出る案内なんだ。
  2. 2

    ファイルをタップ

    ダウンロードが終わった通知をタップしてね。通知が消えちゃってたら、Files や ダウンロード を開いて、imanoimai-1.1.1.apk をさがしてタップ！

  3. 3

    インストールを許可してね

    この提供元のアプリはインストールできません って出たら、設定 を押して、出てきたスイッチをオンにしてね。そのまま戻れば続きからいけるよ。

    こわれてないよ！ Google Play 以外から入れるアプリなら、どれでも かならず一度は聞かれる確認なんだ。許可はこのアプリにだけ効くから、ほかのアプリには影響しないよ。
  4. 4

    警告が出ても だいじょうぶ

    不明なアプリ っていう警告が出るよ。詳細 を押してから インストールする を選んでね。

    ウイルスが見つかったわけじゃないよ！ Google に登録してないアプリ ぜんぶに出る案内なんだ。気になるときは、渡してくれた人にファイルが合ってるか聞いてみてね。
  5. 5

    カメラを許可したら かんせい！

    さいしょに、カメラを使う理由の説明が出るよ。つづける を押すと端末から許可を聞かれるから 許可 を選んでね。カメラが使えないと AR は動かないんだ。

    まちがえて拒否しちゃっても平気！ アプリの中に設定を開くボタンが出るから、そこから許可しなおせるよ。

iPhone のいれかた

iPhone はアプリを直接入れられないから、AltStore という道具を使うよ。

さきに知っておいてね。 iPhone に入れるには パソコン（Windows でも Mac でも OK）と Apple ID が必要だよ。それと、入れたアプリは 7 日たつと開けなくなるから、そのつど入れなおしてね。これは Apple のきまりで、どうにもできないんだ。
いちばん大事！ AltStore は 2 しゅるいあるよ

おなじ「AltStore」って名前で、ぜんぜん別のアプリが 2 つあるんだ。このガイドで使うのは AltStore Classic のほう。iPhone で altstore.io をひらいて自分でダウンロードすると AltStore PAL のほうに案内されちゃって、いまのいまい は入れられないよ。

だいじょうぶ、まようことはないよ。 下の手順 4 でパソコンから入れるのが、ちゃんと Classic のほうなんだ。iPhone で altstore.io を開く必要はまったくないから、そのまま順番にすすんでね。

  1. 1

    パソコンの準備

    Windows さきに iTunes と iCloud を入れておいてね。Microsoft Store 版だと動かないから、かならず Apple の公式サイトから落としたものを使ってね。

    Mac なにも準備はいらないよ。次にすすんでね。

  2. 2

    AltServer を入れて起動する

    パソコンで altstore.io を開いて、AltServer をダウンロードしてね。

    Mac 中身の AltServer を「アプリケーション」フォルダに入れて、ダブルクリックで起動。

    Windows zip を展開して Setup.exe を実行。入れ終わったら、スタートメニューで「AltServer」を検索して、右クリック →「管理者として実行」で起動してね。ネットワークの許可を聞かれたら「許可」を選んで。

    アイコンはここに出るよ。
    Mac 画面のいちばん上の右はし。時計や Wi-Fi のマークがならんでいるところに、ひし形（◆）のアイコンが増えるよ。
    Windows 画面の右下、時計のとなり。見つからないときは ^ をクリックすると、かくれているアイコンが出てくるよ。
    デスクトップやドックには出ないよ。 ふつうのアプリみたいにウィンドウが開かないから「入ってないのかな」と思いがちだけど、上の場所を見てみてね。
  3. 3

    iPhone をつないで「信頼」する

    iPhone をパソコンに USB でつないでね。このとき iPhone のロックを解除して、ホーム画面が見えている状態にしておいて。ロックされたままだとパソコンと話せないんだ。

    つなぐと iPhone に このコンピュータを信頼しますか？ と出るから、信頼 を押して、パスコードを入れてね。

    これが「信頼」だよ。 このパソコンに iPhone の中身をさわる許可をあげる操作なんだ。1 回やれば覚えてくれるよ。もし聞かれなかったら、ケーブルを抜いてもう一度さしてみてね。

    そのあと、Wi-Fi 経由でもやりとりできるようにしておくよ。

    Mac Finder のサイドバーで iPhone をクリック →「一般」タブを下までスクロール →「オプション」の中の Wi-Fi に接続時にこの iPhone を表示 にチェック → 右下の 適用。

    Windows iTunes を開いて Apple ID でサインイン → iPhone の画面で Wi-Fi 経由でこの iPhone と同期 にチェック。

    ここを忘れると失敗するよ。 USB でつないでいても、AltServer は Wi-Fi の道を使って iPhone と話すんだ。このチェックが入っていないと「デバイスに接続できません」って言われちゃう。
  4. 4

    iPhone に AltStore を入れる

    さっきのひし形アイコンをクリックすると、メニューが開くよ。Install AltStore にカーソルを合わせると、右に自分の iPhone の名前が出てくるから、それを選んでね。

    Apple ID とパスワードを聞かれるから入力してね。

    ここで入るのが Classic だよ。 このメニューから入ったものが正解の AltStore Classic。iPhone 側でさがしに行かなくて大丈夫！
    Install AltStore ってなにをしてるの？ あなたの Apple ID で「自分用のアプリ」として署名して、iPhone に入れているんだ。だから Apple ID が必要なんだよ。
    6 けたの数字を聞かれたら。 二段階認証のコードだよ。通知が来ないときは iPhone で自分で出せるよ。
    設定 → いちばん上の自分の名前 → サインインとセキュリティ → 2 ファクタ認証 → 確認コードを入手

    しばらく待つとパソコンに「できたよ」の通知が出て、iPhone のホーム画面に AltStore のアイコンが増えるよ。出てこないときは iPhone を再起動してみてね。

  5. 5

    iPhone で信頼とデベロッパモード

    設定 → 一般 → VPN とデバイス管理 → 自分の Apple ID をタップ → 信頼。

    つぎに 設定 → プライバシーとセキュリティ → デベロッパモード をオンにしてね。iPhone の再起動が必要だよ。

    1 回だけの設定だよ。 アプリを入れるたびにやる必要はないんだ。あとからオフに戻すこともできるよ。
  6. 6

    AltStore に「いまのいまい」を登録する

    AltStore を開いて Browse タブ → 右上の + を押して、下のアドレスを入れてね。

    https://imaiyuji.github.io/imanoimai-guide/altstore.json

    登録すると、一覧に「いまのいまい」が出てくるよ。

    「マーケットプレイス ID が欠落しています」って出たら。 それは AltStore PAL のほうを開いちゃってるよ！ Browse と My Apps のタブがあるほうを開いてね。見あたらなかったら、手順 4 をもう一度やれば入るよ。
  7. 7

    インストールして、カメラを許可

    一覧の「いまのいまい」をタップして FREE を押すとインストールがはじまるよ。パソコンの AltServer は起動したままにしておいてね。

    ひらいたら、カメラの許可を聞かれるから 許可 を選んでね。

    7 日たったら。 AltStore をひらいて My Apps → Refresh All を押すと、また開けるようになるよ。パソコンの AltServer が起動していて、同じ Wi-Fi につながっている必要があるんだ。

こまったとき

よくあるものを集めたよ！

「アプリがインストールされていません」って出る

まえの版がもう入っていて、配る用のものと種類が違うときに出るよ。いちど アンインストールしてから、もう一回 入れなおしてみてね。

インストールが止められて進めない

Xiaomi・Redmi・OPPO なんかだと、外から入れるアプリが きびしく止められてることがあるよ。設定 → アプリ → 特別なアプリアクセス → 不明なアプリのインストール とすすんで、ダウンロードに使ったアプリ（Chrome や Files）を許可してね。

今井ちゃんが出てこない

平面をうまく見つけられてないみたい。明るいところで、模様や物のある床や机を、端末をゆっくり動かしながら映してみてね。まっ白なテーブルや暗い部屋は ちょっと苦手なんだ。12 秒くらい見つからないと、画面の下にヒントが出るよ。

カメラの映像が出なくて、今井ちゃんだけ出てくる

その端末が AR に対応してないときの表示だよ。AR は使えないけど、今井ちゃんを見たり動かしたりはできるよ。対応してるかどうかは、Google の ARCore 対応リストで確認できるよ。

撮った写真が どこにあるか わからない

端末のギャラリーに いまのいまい っていうアルバムができてるよ。ほぞん先は Pictures/いまのいまい だよ。

アプリを消したい

ホーム画面のアイコンを長おしして、アンインストールを選んでね。撮った写真はギャラリーに残るから、消えちゃわないよ。

あんしんのために

ストアを通さないアプリだから、気になるところを正直に書いておくね。

ストアを通っていないけど、安全なの？

正直に言うと、Apple や Google の審査は受けていないよ。ストアのアプリみたいに、第三者がチェックしてくれたわけじゃないんだ。

だから最後は「渡してくれた人を信じられるか」になる。知らない人から回ってきたリンクなら、入れないほうがいいよ。

このアプリを配っているのはお兄ちゃんだよ。気になることがあったら X の @26KC1011 に聞いてみてね。

写真やカメラの映像は、どこかに送られる？

送られないよ。 カメラの映像は画面に映すためだけに使っていて、外には出していないんだ。

撮った写真も端末のなかに保存されるだけ。Android はギャラリーの「いまのいまい」アルバム、iPhone は写真アプリのカメラロールに入るよ。

どんな通信をしているの？

アプリ自身が通信することはないよ。 通信するためのコードが 1 行も入っていないし、使われかたを集める仕組み（アクセス解析）も広告も入れていないんだ。

Android では「インターネット」の権限が付いているけど、これは AR のしくみ（Google の ARCore）が必要としているもので、このアプリが何かを送るためのものじゃないよ。

「提供元不明のアプリ」を許可して大丈夫？（Android）

この許可はアプリごとに効くよ。「Chrome からのインストールを許す」みたいな指定だから、端末ぜんぶが無防備になるわけじゃないんだ。

入れ終わったら戻しておいても大丈夫。設定 → アプリ → 特別なアプリアクセス → 不明なアプリのインストール から、いつでもオフにできるよ。

Apple ID を入れるのがこわい（iPhone）

AltStore に入力した Apple ID とパスワードは、Apple にだけ送られるしくみだよ。AltStore を作った人にも、わたしたちにも届かないって公式に書かれているんだ。

それでも気になるなら、AltStore 専用の Apple ID を新しく作る手もあるよ。無料で作れるし、ふだん使っているアカウントと切り離せるから安心だと思う。

デベロッパモードをオンにして大丈夫？（iPhone）

これは「開発中のアプリを動かしてもいい」という関門を開ける設定だよ。ふだん閉じているものを開けるので、なんでも入れていい状態になるわけじゃないけど、気をつける必要はあるんだ。

信頼できないアプリを入れないようにしていれば大丈夫。使い終わったら、同じ場所からオフに戻せるよ（再起動が必要）。

中身を自分で確かめたい

ソースコードを公開しているよ。 誰でも読めるようになってるよ。

https://github.com/ImaiYuji/imanoimai-source

カメラの映像をどう使っているか、写真をどこに保存しているか、通信をしているかどうか、ぜんぶコードで確かめられるよ。

ただしキャラクターのモデルとモーションは入っていないんだ。作った人が別にいて、そのまま配ることは許されていないから。だからビルドはできないけど、中身を読むことはできるよ。

わからないことがあれば、お兄ちゃん（X @26KC1011）に聞いてみてね。

やめたくなったら

ふつうのアプリと同じように、アイコンを長おししてアンインストールできるよ。撮った写真は残るから安心してね。

iPhone なら、AltStore の My Apps からも消せるよ。

つかうまえに、ひとつだけ

かたい話だけど、だいじなことだから読んでね。

これは個人がつくった、おまけみたいなアプリだよ

会社がつくった製品じゃなくて、ひとりで趣味としてつくって、無料でおすそわけしているものなんだ。App Store や Google Play の審査も通っていないよ。

だから、ちゃんと動くことを約束できないし、なにか起きても責任を負えないんだ。 たとえばこんなこと。

  • アプリが落ちる、うまく動かない、キャラクターが変な表示になる
  • 端末が熱くなる、電池がへる、動きがおもくなる
  • 撮った写真が保存されない、消えてしまう
  • インストールの作業のとちゅうで、端末の設定がおかしくなる

こういうことが起きても、なおしてあげられないかもしれないし、損害を埋めることもできないんだ。自分の責任でつかってねっていうのが、正直なところ。ごめんね。

もちろん、わざと悪いことをするようなものは入れていないよ。中身が気になる人のためにソースコードも公開しているし、なにか困ったらできるはんいで相談にのるつもりだよ。

大事なデータが入っている端末や、お仕事でつかっている端末には入れないほうがいいと思う。

Apple・Google・AltStore とは関係ないよ。 このアプリは、そのどこの会社ともつながりがないんだ。インストールに使う AltStore もべつの人がつくった道具で、そちらで起きたことにも責任を負えないよ。
撮った写真を SNS にあげるときの、たったひとつのおやくそく

このアプリで撮った写真を SNS にあげていいのは、UCA（明治学院大学漫画研究会）専用の Twitter アカウントの中だけだよ。

じぶんの個人アカウントや、そのほかの SNS にはあげないでね。ごく身内でたのしむためにつくったアプリだから、ここだけはかならず守ってほしいんだ。

もちろん、自分の端末に保存して、手もとで見てたのしむのは自由だよ！ 友だちに直接見せるのも大丈夫。あくまで「ひろく公開しないでね」というお願いだよ。

キャラクターや衣装には、つくった人がいるよ。 3D モデルもポーズも、それぞれ別の作者さんの作品を、規約を守ってつかわせてもらっているんだ。アプリで撮った写真をつかうときは、その作者さんの決まりごとにも気をつけてね。とくに、人を傷つける使いかたや、作者さんがいやがる使いかたはしないでね。
こまったら聞いてね。 お兄ちゃん、もしくは X の @26KC1011 まで。ぜんぶ解決できるとはかぎらないけど、できるだけ力になるよ！
